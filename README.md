# CICLO

Sistema web de gestión y trazabilidad para el servicio de esterilización de un hospital.
Trabajo Final Integrador (TFI) de la Tecnicatura Universitaria en Programación, UTN Facultad Regional Tucumán.

## Stack

- Frontend: React y React Router, con Axios.
- Backend: FastAPI (Python) y SQLAlchemy.
- Base de datos: PostgreSQL con migraciones de Alembic.
- Comunicación: HTTP/JSON con autenticación JWT.

## Estructura

- `backend/`: API REST.
- `frontend/`: interfaz web.
- `docs/bitacora/`: registro del desarrollo.
